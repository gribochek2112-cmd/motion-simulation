📚 Теоретический материал

Основные понятия кинематики

Кинематика - раздел механики, изучающий движение тел без учета сил, вызывающих это движение.

Основные характеристики движения:

  • Траектория - линия, по которой движется тело
  • Путь (s) - длина траектории
  • Перемещение (Δr) - вектор, соединяющий начальное и конечное положение
  • Скорость (v) - изменение положения за единицу времени
  • Ускорение (a) - изменение скорости за единицу времени

Классификация движений:

Тип движения Характеристика Ускорение
Равномерное Скорость постоянна a = 0
Равноускоренное Скорость возрастает a > 0
Равнозамедленное Скорость убывает a < 0
По окружности Траектория - окружность a_c = v²/r

Средняя и мгновенная скорость:

Средняя скорость: v_ср = s/t

Мгновенная скорость: v = ds/dt

Среднее и мгновенное ускорение:

Среднее ускорение: a_ср = Δv/Δt

Мгновенное ускорение: a = dv/dt

Графики движения:

  • График s(t) показывает зависимость перемещения от времени
  • График v(t) показывает изменение скорости во времени
  • График a(t) показывает постоянство или изменение ускорения

Свободное падение:

Частный случай равноускоренного движения с g ≈ 9.8 м/с² (10 м/с² для упрощения)

  • h = (g·t²)/2
  • v = g·t
  • v² = 2·g·h

Важные примечания:

  • Все векторные величины имеют направл��ние
  • Путь всегда положителен, перемещение может быть отрицательным
  • При равномерном движении s = v·t, при ускоренном необходимо использовать формулы с ускорением
  • Угловая скорость связана с линейной: ω = v/r
